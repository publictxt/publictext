# WikiTool

In progress. A multiplatform .NET tool for handling multiple wikis.

- Core wiki libraries
- Converts between wiki formats and syntaxes, including Obsidian ↔ md-wiki — how `[[wikilinks]]` vaults become [PublicTxt-Pages](PublicTxt-Pages.md)-ready Markdown links
- Copies between wikis by search, tag expressions (`tag1 + tag2 - tag3`) and attributes
