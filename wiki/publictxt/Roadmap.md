## v1

1. Keep notes and writing in a Git repository — done
2. Publish to the web for free — done ([Publishing](Publishing.md))
3. Pull selected pages from other people's PublicTxt repositories into a local aggregate view to browse and search — next

## Later

- **Desktop and web apps** that hide Git, with a local cache for fast search
- **Community**: discussion, profiles, groups, moderation; public / semi-public / private content
- **MetaWeb**: a browser extension showing Git-stored notes about web pages; W3C Web Annotation export
- **Federation**: ActivityPub; Git commits as public records
- **Richer data**: RDF semantic edges, weighted links, a TerminusDB graph backend, reputation and peer review

Deferred until the v1 aggregation-and-publish story works and is used.
