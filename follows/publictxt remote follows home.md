# Follows

The PublicTxt repos this one follows, one note per repo ([ADR-0014](../wiki/publictxt/docs/adr/0014-follows-are-notes.md)). Pages mirrored from them are under `community/` ([ADR-0017](../wiki/publictxt/docs/adr/0017-mirrors-in-community.md)); pages forked from them are in this repo's own folders, and each note lists both.

| Follow | Source |
|---|---|
| [publictxt-pages](publictxt-pages.md) | [publictxt/publictxt-pages](https://github.com/publictxt/publictxt-pages): docs of the static site generator |
| [publictxt-facets](publictxt-facets.md) | [publictxt/obsidian-publictxt-facets](https://github.com/publictxt/obsidian-publictxt-facets): docs of the Facets plugin |
| [publictxt-remotes](publictxt-remotes.md) | [publictxt/obsidian-publictxt-remotes](https://github.com/publictxt/obsidian-publictxt-remotes): docs of the Remotes plugin |
| [txt](txt.md) | [jaysen/txt](https://github.com/jaysen/txt): Jaysen's public wiki and blog |
| [pwiki](pwiki.md) | A local repo: Jaysen's personal wiki |

How follows work: [Obsidian PublicTxt Remotes](../wiki/publictxt/projects/obsidian-plugins/Obsidian-PublicTxt-Remotes.md), [spec §3.2](../wiki/publictxt/docs/spec/publictxt-spec.md#32-follows).
