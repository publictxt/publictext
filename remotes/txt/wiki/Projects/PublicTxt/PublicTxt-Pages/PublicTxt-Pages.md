#publictxt #compsci #dev #project 

This project is a static-to-dynamic site generator, that creates [publicTxt](https://github.com/publictxt/publictext) sites (like this one) automatically from an [Obsidian.md](../../../Computer-Science/Software/Obsidian/Obsidian.md.md) wiki, and publishing it using Github pages (no host or database required)
## how?
- Static-site generator with dynamic client-side layer
- Python pre-processing, 
- Hugo build, 
- [Pagefind](../Tools/Pagefind.md) full-text search
- JS faceted browse for PublicTxt/Obsidian repos
- Works directly against a standard Obsidian-style Markdown vault 
- with no reliance on [Project PublicTxt](Project%20PublicTxt.md)-specific syntax transforms
