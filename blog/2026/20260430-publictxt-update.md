# PublicTxt update: narrowing the focus
#publictxt #project

Updated the project README to reduce the focus to the core set of features: primarily **selective aggregation** using Git repositories.

Plain-text Markdown in Git, published by static hosting, is the substrate. Pulling chosen subsets of other people's repositories into a local aggregate view is the value. Community features, browser extensions, federation and graph backends are deferred.
