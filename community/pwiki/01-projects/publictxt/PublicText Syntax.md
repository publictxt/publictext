## Weighted Attributes 
- Inspired by [[community/pwiki/02-areas/km/pkm/Obsidian/plugins/Obsidian DataView Plugin]]'s tags 
	- eg: [idea::90], [difficulty::30] 
- Weight or strength or number denoted by ::x

### Attribute entities
- Defines the edge between node and a type of attribute entity
- The above example [idea::90] says this is connected to the idea node
- The Idea page/node
-  has following attribute weighting defined 
	- to be between 1 & 100 using min::0, max::100, 
	- defines weight::value, as opposed to 
		- amount/
		- percentage/
		- distance/
		- time/
		- occurrences 
	- defines value using best::100
	- defines related nodes
